SSE Inspector

Privacy Policy

Overview

SSE Inspector is a Chrome DevTools extension for capturing and debugging Server-Sent Event (SSE) streams. Your privacy is important to us. This policy explains what data the extension accesses and how it is handled.

Data We Collect

We collect no data whatsoever.

SSE Inspector does not collect, store remotely, transmit, sell, or share any personal information or usage data. There are no analytics, no telemetry, and no external network requests made by the extension itself.

Data Stored Locally

SSE Inspector temporarily stores the following data on your device only, in your browser's local storage:

  • Captured SSE event payloads — the raw text content of Server-Sent Events observed on pages you visit while using DevTools. This data is kept in memory per browser tab and optionally written to chrome.storage.session (cleared when the browser closes) if you enable the "Persist across refreshes" setting.
  • Your extension preferences — a single boolean flag (whether session persistence is enabled) stored in chrome.storage.local.

All locally stored data is cleared automatically when the corresponding browser tab is closed, when you use the "Clear" button in the extension panel, or when the browser session ends.

Permissions Explained

  • Access to all websites (<all_urls>) — SSE Inspector must run on any page you are debugging, since SSE streams can be served from any domain. The extension only intercepts EventSource connections and fetch() calls that return a text/event-stream content type. No other page content is read, modified, or transmitted.
  • Storage — Used to save your persistence preference and optionally buffer captured events across page refreshes. No data leaves your device.
  • Scripting / Tabs — Required to inject the monitoring script into the inspected page and to communicate between the DevTools panel and the browser tab.

Third Parties

SSE Inspector has no dependencies on third-party services, CDNs, analytics platforms, or cloud infrastructure. The extension is entirely self-contained.

Children's Privacy

SSE Inspector is a developer tool not directed at children. We do not knowingly collect any information from anyone.
